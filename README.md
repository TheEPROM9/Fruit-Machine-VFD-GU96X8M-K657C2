# Fruit-Machine-VFD-GU96X8M-K657C2
The GU96X8M-K657C2 is part of the GU96X8M series of VFD displays used in gambling machines, often deployed in pubs here in the UK.

Website Overview & Description: https://www.theeprom9.co.uk/electronics/projects-such/fruit-machine-vfd

My partner has worked on code to convert these to running on an ESP32 but has not published it yet, that one is up to him.
